# Истинна ли формула в мире w₁?

Тренажёр для начинающих к упражнению 8.19 (семантика Крипке): для каждой из 35 формул решите, истинна она в мире w₁ или ложна, и проверьте ответ. Наведите указатель на мир, чтобы увидеть достижимые из него миры.
