Истинна ли формула в мире w1?

Для каждой формулы решите, истинна она в мире w1 или ложна, и проверьте ответ. Наведите указатель на мир (или нажмите на него), чтобы увидеть, какие миры достижимы из него.

Нажимайте кнопки или печатайте: ~ для ¬, & для ∧, | или v для ∨, -> для →, <-> для ↔, [] для □, <> для ◇, 0 для ⊥, 1 для ⊤. Без скобок ∧ связывает сильнее ∨, затем →, затем ↔.
